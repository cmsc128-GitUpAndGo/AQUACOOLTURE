# AQUACOOLTURE

A centralized inventory management system for an aquaculture laboratory that allows users to check the availability of primers and reagents. Users can also search for a target species and view the primers associated with that species when available in the system.

## Features 

The application is planned to support the following operations:
- Manage primer records
- Manage reagent records
- Check primer and reagent availability
- Search for primers by target species
- View inventory information
- Manage user accounts and access roles
