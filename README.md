# AQUACOOLTURE

A centralized inventory management system for an aquaculture laboratory that allows users to check the availability of primers and reagents. Users can also search for a target species and view the primers associated with that species when available in the system. This application also supports inventory management, supply requests, and role-based access for laboratory managers, teachers, and students.

## Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js and Express.js
- **Database:** MongoDB

### Tech Stack Description

AQUACOOLTURE will use the MERN stack to develop a web-based inventory management system.

- React.js will be used to build the user interface, including the visitor homepage, member dashboard, admin dashboard, primer catalog, reagent catalog, and inventory management pages.
- Node.js and Express.js will handle server-side operations, API endpoints, authentication, inventory transactions, and supply request processing.
- MongoDB will store primer records, reagent records, target species information, inventory quantities, user accounts, and request histories.

This stack supports a centralized web application accessible through a browser, allowing laboratory members and managers to access the system without installing a desktop application.

## Features 

The application is planned to support the following operations:
- Manage primer records
- Manage reagent records
- Check primer and reagent availability
- Search for primers by target species
- View inventory information
- Manage user accounts and access roles
